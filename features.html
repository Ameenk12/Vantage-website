Everything you need to keep a useful record.

No speculative features here. This page covers what Vantage does today across iPhone, iPad, and Apple Watch.

01

Nutrition

Describe the meal. Check the details. Save it.

Use the input that fits the moment, then review anything estimated before it becomes part of your diary.

Fast inputs
Natural-language text and voice, barcode scan, USDA search, manual foods, and saved meals.
Recipes
Create from conversation, text, a shared link, or a photo; save and reuse portions.
Daily context
Calories, protein, carbs, fat, meal groups, seven-day history, and fixed or adaptive targets.

02

Training

Structure when you want it. A blank session when you don’t.

Build a program, reuse a template, or start quickly. The logger keeps the useful context near the set without crowding it.

Session tools
Previous performance, exercise and session notes, rest timer, plate calculator, set reordering, and workout history.
Flexible logging
Weight and reps, duration, distance, warm-up and working sets, metric or imperial units.
Exercise library
890 exercises with search, equipment and muscle filters, instructions, and body maps.

03

Progress

Compare like with like.

Use consistent date ranges across training, nutrition, and body data so a change has context.

At a glance
Workouts, volume, time trained, average calories, weight, and period-over-period comparisons.
Training detail
Estimated strength, personal records, exercise history, consistency, and muscle-group balance.
Body trends
Weight and measurements with smoothed trends and a focused body-progress view.

04

Apple devices

One record, fitted to each screen.

iPhone

The complete daily app with focused navigation and native controls.

iPad

Adaptive two-column dashboards, wider charts, denser grids, and live-workout context.

Apple Watch

Start and log workouts, follow rest, see the diary, use saved meals, dictate food, and add a Vantage complication.

05 / Data & control

Local first

The app remains useful without surrendering control.

Core records work locally and an account is optional. Sign-in enables cloud sync and provider-backed features.

Privacy

Permission by feature

Camera, photos, microphone, speech, notifications, and health access remain tied to features you choose.

Portability

Export your records

Export supported nutrition, workout, body, and profile data from the app.

Accounts

Delete when you’re done

Clear local records or request account and cloud-data deletion from Vantage.

Appearance

Make it yours

Multiple visual themes, light and dark appearance, unit controls, reduced motion, and accessibility-aware states.

Sync

Local use comes first

Guest use stays on device; optional accounts add backup and multi-device restoration.

AI features

Reviewable and separate

Provider-backed tools require an account. Local workout and meal logging do not.
